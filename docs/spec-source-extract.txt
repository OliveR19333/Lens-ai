1. System Overview
The GAS Property Mapping System is a mobile-first Progressive Web App (PWA) that enables field operators to input a property address on the day of a job, automatically generate a DJI-compatible Waypoint mission, fly the property, and produce two scaled planning maps: a flat orthomosaic grid map and an elevation change map. Both maps print on a single 8.5" × 11" sheet at a locked scale that can be proportionally enlarged to any size (e.g., 25" × 30" grid paper).

The system is purpose-built for two primary use cases:
Irrigation system design and layout planning
TNC hardscape and landscape construction planning

2. End-to-End User Workflow
The complete workflow from address input to printed map follows these phases:

Phase 1 — Mission Setup (Field, Day-Of)
Open PWA on iPhone (works offline)
Enter property address manually
System geocodes address → determines county → loads cached parcel boundary
Review parcel boundary overlay on map
Confirm and generate Waypoint mission file (KMZ)
KMZ downloads to phone → loads into DJI Fly app automatically
Fly mission with Mini 4 Pro

Phase 2 — Processing (Post-Flight, WiFi Required)
Upload drone images to WebODM via PWA or desktop
WebODM generates orthomosaic (GeoTIFF) + Digital Elevation Model (DEM)
Backend runs AI feature detection on orthomosaic
System identifies and flags: water bodies, tree clusters, structures, driveways

Phase 3 — Map Output
User selects print scale (auto-calculated to fit 8.5" × 11")
System generates Map 1: Flat B&W orthomosaic with parcel boundary + feature labels + grid
System generates Map 2: Elevation contour map with slope direction indicators + feature labels
Both maps export as print-ready PDF at locked scale with scale bar
Scale ratio printed on map for proportional enlargement to 25" × 30" grid paper

3.4 DJI Fly Integration
The KMZ mission file must be transferred to the DJI RC controller. The recommended integration flow is:
Generate KMZ on backend → return download URL to PWA
PWA triggers iOS share sheet with KMZ file
User selects "Copy to DJI Fly" or saves to Files app → manually imports to DJI Fly
⚑  NOTE: Full programmatic DJI Fly deep-link integration is not publicly documented by DJI. The share sheet approach is the most reliable cross-device method. Monitor DJI developer updates for direct app-to-app transfer APIs.

5.2 Monthly Sync Process
The Celery beat scheduler runs a monthly parcel sync job:
Celery beat fires on the 1st of each month at 2:00 AM local time
For each enabled county: download latest shapefile or GeoJSON from GIS portal
Convert shapefile to GeoJSON using pyogrio or geopandas if needed
Store in PostGIS database with county index
Package per-county GeoJSON bundles for PWA download (compressed, ~10–30MB each)
PWA detects new version hash on next WiFi connection → prompts user to sync
User confirms → IndexedDB updated with fresh parcel data

5.3 Parcel Lookup Logic
Given a geocoded lat/lng coordinate, the backend performs a PostGIS point-in-polygon query:
-- PostGIS query: find parcel containing the given point
SELECT parcel_id, owner, address, geom
FROM parcels_{county}
WHERE ST_Contains(geom, ST_SetSRID(ST_MakePoint({lng}, {lat}), 4326))
LIMIT 1;

-- Return GeoJSON of parcel boundary
SELECT ST_AsGeoJSON(geom) FROM parcels_{county}
WHERE parcel_id = {parcel_id};
 |

6.2 KMZ File Structure
A DJI-compatible mapping KMZ contains a wayline.wpml file inside a wpmz folder. Key structure:
mission.kmz
└── wpmz/
    ├── waylines.wpml     ← flight path, altitude, overlap settings
    └── template.kml      ← area boundary polygon

<!-- waylines.wpml core fields -->
<missionConfig>
  <flyToWaylineMode>safely</flyToWaylineMode>
  <finishAction>goHome</finishAction>
  <exitOnRCLost>goContinue</exitOnRCLost>
  <droneInfo><droneEnumValue>67</droneEnumValue></droneInfo>  <!-- Mini 4 Pro -->
</missionConfig>
 |

6.3 Mission Generation Logic
Receive parcel boundary GeoJSON polygon
Calculate bounding box + add 15ft buffer around all edges
Compute grid flight lines at selected altitude and overlap settings
Generate waypoints along each flight line with photo trigger intervals
Build waylines.wpml and template.kml XML files
Zip into .kmz archive and return to PWA for download
⚑  NOTE: Use the Waypoint OS API (Pilotbyte) for mission file generation where the API supports programmatic KMZ creation. If direct API calls are not available, implement the KMZ builder natively in Python using the DJI WPML 2.0 specification.

 | Obstacle avoidance, root zone planning

# Python detection pipeline pseudocode
from ultralytics import YOLO
import rasterio, numpy as np, geopandas as gpd

# 1. Load ortho, tile into chips
chips = tile_geotiff("orthophoto.tif", size=640, overlap=64)

# 2. Run YOLO on each chip
model = YOLO("yolov8n-aerial-property.pt")
detections = [model(chip) for chip in chips]

# 3. Merge detections, apply geo transform
features = merge_detections_to_geojson(detections, ortho_transform)

# 4. Water body detection via spectral analysis
water_polygons = detect_water_spectral("orthophoto.tif")
features["features"].extend(water_polygons)

# 5. Slope from DTM
slope, aspect = compute_slope_aspect("dtm.tif")
slope_vectors = slope_to_arrows(slope, aspect, spacing=50)
 |

9.3 Scale Calculation
The system auto-calculates the best-fit scale for the parcel on 8.5" × 11" with 0.5" margins (printable area: 7.5" × 10"):
# Scale calculation logic
printable_width_inches  = 7.5
printable_height_inches = 10.0

# Get parcel dimensions in feet (from GeoJSON bounds)
parcel_width_ft  = calculate_width(parcel_geojson)   # e.g., 300 ft
parcel_height_ft = calculate_height(parcel_geojson)  # e.g., 400 ft

# Calculate scale denominators needed to fit each dimension
scale_w = parcel_width_ft  / printable_width_inches   # 300/7.5 = 40
scale_h = parcel_height_ft / printable_height_inches  # 400/10  = 40

# Use the larger (more zoomed out) scale, round up to nearest 5
scale = ceil(max(scale_w, scale_h) / 5) * 5   # → 1" = 40 ft

# Print note on map: "Scale: 1 inch = 40 feet | Enlarge 3.33x for 25x30 grid"
enlargement_factor = 25 / 8.5   # = 2.94x  (or 30/11 = 2.73x for height)
 |
