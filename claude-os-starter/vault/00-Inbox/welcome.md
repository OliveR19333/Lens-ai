# Welcome to your brain

This folder (`00-Inbox`) is where everything lands first — ideas, links,
half-thoughts. Don't organize while capturing. Once a week (or when you run
`/plan-today`), file inbox notes into the right folder and add `[[links]]`.

Start by filling in [[tnc-offer]] — it's the note every skill leans on.

The graph in Obsidian grows from links like the one above. A note nobody
links to doesn't exist as far as the brain is concerned.
